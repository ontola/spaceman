Find it, clean it, keep it safe

SpaceMan shows your disk as a treemap or a sorted list, then points out what you can usually remove without missing it.

Explore

Drill through folders, largest first, as a treemap or a list with sizes and shares. Results appear while the scan is still running.

Clean up

Suggestions for caches, build output like node_modules and Rust target, logs, the Trash, old downloads and huge files. Nothing is ticked for you.

Do not touch

Protect any file or folder. Protected items are never suggested and cannot be removed. Everything else goes to the Trash, so it can be undone.

Very fast, and it remembers

The scanner is written in Rust and walks your disk in parallel. Results are cached, so the next start is instant.

Questions

Is it safe?

SpaceMan only removes what you select. On desktop, items go to the Trash or Recycle Bin, so you can restore them. Folders apps expect to exist, like caches, are emptied instead of removed.

Windows warns about the installer.

The Windows installer is not code-signed yet. Choose More info, then Run anyway. It installs for your user only and needs no admin rights.

How do I run the Linux version?

Make the AppImage executable (chmod +x SpaceMan-Linux-x86_64.AppImage) and run it. A .tar.gz is also on the releases page.

Why does macOS ask for Full Disk Access?

Only if you want to scan protected places like Mail or Messages. Without it, SpaceMan scans everything else.

Does it send my data anywhere?

No. Scanning and cleanup happen on your device. There are no accounts and no tracking.
